# Python Data Analysis & Visualization Portfolio

Welcome to the **Python Data Analysis & Visualization Portfolio** repository! This repository serves as a centralized hub for data manipulation, exploratory analysis, statistical modeling, and data visualization projects developed using modern Python libraries.

---

## 🛠️ Tech Stack & Tooling

The projects in this repository rely on the following Python ecosystem tools:

- **Data Processing & Manipulation:** `Pandas`, `NumPy`
- **Visualization:** `Matplotlib`, `Seaborn`, `Plotly`
- **Statistical Analysis & Science:** `SciPy`, `Statsmodels`
- **Environment:** Jupyter Notebooks (`.ipynb`) & Python Scripts (`.py`)

---

## 📂 Repository Contents

This repository is structured around core data analysis workflows, transitioning from foundational data cleaning to advanced statistical exploration:

```text
├── data/                       # Datasets used across projects (CSV, JSON, Excel)
├── notebooks/                  # Interactive Jupyter Notebooks for analysis
│   ├── data_cleaning.ipynb     # Preprocessing, handling missing values, and scaling
│   ├── exploratory_eda.ipynb   # Univariate and bivariate exploratory analysis
│   └── advanced_analysis.ipynb # Statistical modeling, hypothesis testing, and custom visual plots
├── scripts/                    # Reusable Python modules and visualization functions
├── outputs/                    # Exported high-resolution charts, plots, and figures
└── reports/                    # Written documentation, findings, and summaries
